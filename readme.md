# GravityNote - グラビティノーツ

## 概要説明
音ゲー＆アクション＆重力操作の新感覚ゲーム！リズムに合わせて爽快に敵を撃破しよう。
重力操作を用いて、天井や床も走り回って華麗に立ち回り、ステージクリアを目指せ！
通常攻撃で倒す敵、触れると取得のオーブ、バリアは直前にジャスト回避！虹を渡れば一層楽しく！

## 操作方法
### コントローラ
- Lスティック,十字キー：平面移動
- Rスティック：重力移動
- トリガー：攻撃
### キーボード
- Enter/Space：決定
- WASD：平面移動（回避）
- 矢印キー：重力移動
- Space：攻撃 

### その他のキー
- Escape3秒長押し：曲選択へ戻る
- F1：最初からやり直す（jsonも再読み込みされます）
- F2：スクリーンショット
- F3：ポーズ・スタート
- F11：フルスクリーン切り替え
